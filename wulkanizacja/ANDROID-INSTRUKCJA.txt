WULKANIZACJA – PROJEKT PRZYGOTOWANY POD ANDROIDA

Wymagania: Node.js 20+, Android Studio oraz Android SDK.

1. Rozpakuj ZIP na komputerze.
2. Otwórz terminal w folderze projektu.
3. Wykonaj: npm install
4. Wykonaj: npx cap add android
5. Wykonaj: npm run android:sync
6. Wykonaj: npx cap open android
7. W Android Studio wybierz Build > Build Bundle(s) / APK(s) > Build APK(s).
8. APK znajdziesz w android/app/build/outputs/apk/debug/app-debug.apk

Muzyka YouTube wymaga internetu. Uruchom ją przyciskiem w grze.
